# ExoHuman Templates

Agent and system templates for [ExoHuman](https://exohuman.cc) users.

## Structure (growing)

```
agent-templates/    # ready-to-instantiate agent definitions
system-templates/   # system manifests and starter stacks
```

## Use a template

Templates are installable from your instance's Library. This repository is the public, community-facing mirror: browse, fork, improve, and open a PR.

## Contribute

1. Fork → branch → change → PR
2. Templates must be self-contained (no secrets, no absolute paths)
3. English ids/keys; human copy can be localized
